# Task 3 — Machine unlearning

**Public score: 0.0986** (first scored submission 0.0026). Best submission: `t3_P5.pt`, a head-only
edit of the original model. Literature review (French): [VEILLE.md](VEILLE.md).

## The task

- A ViT-B/16 classifier (timm `vit_base_patch16_224`, 100 classes, LayerScale `init_values=1e-4`) and
  3,500 images to forget: 224×224, generated by diffusion, unlabelled, spread over 45 classes.
- No retain set, no labels, no validation data, no gold model. The task is to produce a model that
  behaves like one **retrained without** the forget images, while staying identical elsewhere.
- Metric: forget × retain, set to 0 if hidden validation accuracy falls below 70 %.
  - forget compares the loss distribution (mean and spread) and the KL at T = 2 against gold retrained
    models, on the forget images and on hidden altered copies;
  - retain is the accuracy ratio × 1 / (1 + KL(original ‖ submission)).
- Output: a float32 state dict, loaded with `strict=True`, under 450 MB; evaluated in fp16 autocast.

## How we reasoned

### 1. A local proxy, knowingly weak

[eval.py](eval.py) blocks broken submissions (format, `strict=True`, fp16 drift) and compares
candidates through proxies:

- retain proxy: agreement × exp(−KL) with the original model on out-of-set photos;
- forget proxy: the candidate's loss on the forget images against the original model's loss on
  strongly augmented forget images, used as a stand-in for "never seen".

Without a gold model, this proxy could rank candidates but could not predict the server. The early
submissions confirmed it.

### 2. Reading the metric: imitate, don't destroy

A retrained model still predicts plausible classes on images it never saw. Pushing the forget images
toward uniform or maximizing their loss makes KL(gold ‖ submission) explode. Weight soups between the
original and an NPO-unlearned model scored 0.0012-0.0044: they forgot too little before drifting
elsewhere.

### 3. The one mechanism the server rewarded

A minimal edit of the classification head: the rows of the 45 affected classes are pushed down, and
the backbone is left untouched, so the retain term stays close to 1. Then two sweeps:

| Push strength (T = 1.0) | Public | | Head temperature (strength ×1.75) | Public |
|---|---:|---|---|---:|
| ×1.25 | 0.0567 | | T = 1.2 | 0.0754 |
| ×1.5 | 0.0827 | | T = 1.0 | 0.0941 |
| ×1.65 | 0.0923 | | T = 0.95 | 0.0972 |
| ×1.75 | 0.0941 | | **T = 0.9** | **0.0986** |
| ×2.0 | 0.0792 | | T = 0.8 | 0.0898 |

### 4. Refuted by the server or by the local rule

- Soups, distillation and KL anchoring on out-of-set photos ([make_soups.py](make_soups.py),
  [distill_mix.py](distill_mix.py), [unlearn_anchor.py](unlearn_anchor.py)): 0.001-0.004.
- Removing the 9 classes that hold 130 images each: 0.0205. The gold model lowers the whole class,
  it does not erase it.
- Preserving img2img variants of the forget images: 0.0317.
- Image-conditional distillation of the best head into the last blocks: 4 variants out of 4 failed the
  local rule. The student memorized its training images instead of learning a general rule.
- `margin_edit` (target = second-best logit + margin, last 4 blocks): measured locally on Saturday
  night, never submitted.

## What the top teams did (0.43-0.48)

Read after the event, in the repositories of Murmell, Fable 4.2, LesRooters and WhatThePhoques:

- **A per-image target.** A model that never saw a forget image errs about 4 times out of 5 toward a
  sibling class (Murmell). The target is the original model's runner-up distribution, with the
  memorized class pushed a few logits below the best other class.
- **Learned on the last blocks**, not only on the head, with a KL anchor to the original model on
  crops, mixups and generated variants.
- **A stand-in for the server**: a few-parameter scorer fitted to the team's own public scores
  (WhatThePhoques), or gold stand-ins obtained by re-initializing and re-training the last blocks.

Our head push lowered the right class, but did not move the mass to the sibling class image by image.
`margin_edit` was the closest idea we had, and SCAR, in our own literature review, already pushes forget
features toward the nearest wrong class.
